# Divide Node

Divides the first number by the second.

## Input Ports
- **exec_in** (Flow)
- **a** (Float)
- **b** (Float)

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Quotient

## Properties
None

## Example Usage
a / b (raises error if b is 0)
