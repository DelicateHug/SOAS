# String Replace Node

Finds and replaces text within a string.

## Input Ports
- **exec_in** (Flow)
- **input** (String) - Source string
- **find** (String) - Text to find
- **replace** (String) - Replacement text

## Output Ports
- **exec_out** (Flow)
- **result** (String) - Modified string

## Properties
None

## Example Usage
Replace 'http://' with 'https://' in URLs.
