# List Reduce Node

Reduces a list to a single value using an accumulator expression.

## Input Ports
- **exec_in** (Flow)
- **list** (List) - List to reduce

## Output Ports
- **exec_out** (Flow)
- **result** (Any) - Accumulated result

## Properties
None

## Example Usage
Sum up all severity scores from a list of incidents.
