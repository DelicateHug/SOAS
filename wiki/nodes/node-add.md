# Add Node

Adds two numbers together.

## Input Ports
- **exec_in** (Flow)
- **a** (Float) - First number
- **b** (Float) - Second number

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Sum

## Properties
None

## Example Usage
Connect two numeric outputs to get their sum.
