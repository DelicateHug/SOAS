# List Append Node

Appends an element to the end of a list.

## Input Ports
- **exec_in** (Flow)
- **list** (List) - Existing list
- **item** (Any) - Item to append

## Output Ports
- **exec_out** (Flow)
- **result** (List) - Updated list

## Properties
None

## Example Usage
Build up a list of findings as you process incidents.
