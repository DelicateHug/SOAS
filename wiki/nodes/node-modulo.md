# Modulo Node

Returns the remainder of dividing the first number by the second.

## Input Ports
- **exec_in** (Flow)
- **a** (Float)
- **b** (Float)

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Remainder

## Properties
None

## Example Usage
a % b
