# List Map Node

Transforms each element in a list using an expression.

## Input Ports
- **exec_in** (Flow)
- **list** (List) - List to transform

## Output Ports
- **exec_out** (Flow)
- **result** (List) - Transformed list

## Properties
None

## Example Usage
Extract just the IP addresses from a list of alert objects.
