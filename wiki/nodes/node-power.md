# Power Node

Raises the first number to the power of the second.

## Input Ports
- **exec_in** (Flow)
- **a** (Float)
- **b** (Float)

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Result

## Properties
None

## Example Usage
a ** b
