# String Concat Node

Concatenates two or more strings together.

## Input Ports
- **exec_in** (Flow)
- **a** (String) - First string
- **b** (String) - Second string

## Output Ports
- **exec_out** (Flow)
- **result** (String) - Concatenated string

## Properties
None

## Example Usage
Joins strings: 'Hello' + ' ' + 'World' = 'Hello World'
