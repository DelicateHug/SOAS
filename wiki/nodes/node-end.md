# End Node

Marks the end of an execution path. The automation stops when an End node is reached.

## Input Ports
- **exec_in** (Flow) - Incoming execution
- **result** (Any) - Optional result value

## Output Ports
None - execution terminates here.

## Properties
None

## Example Usage
Place an End node at the end of each branch. Optionally pass a result value for the execution output.
