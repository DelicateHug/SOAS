# List Filter Node

Filters list elements based on a condition.

## Input Ports
- **exec_in** (Flow)
- **list** (List) - List to filter

## Output Ports
- **exec_out** (Flow)
- **result** (List) - Filtered list

## Properties
None

## Example Usage
Filter a list of alerts to only include critical severity.
