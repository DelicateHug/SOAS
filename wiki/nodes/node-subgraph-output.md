# Subgraph Output Node

Defines an output of a subgraph or automation result.

## Input Ports
- **exec_in** (Flow)
- **value** (Any) - Value to output

## Output Ports
None

## Properties
- **port_name** - Name for this output
- **port_type_setting** - Data type of this output

## Example Usage
Use to define what your automation returns as its result.
