# Subtract Node

Subtracts the second number from the first.

## Input Ports
- **exec_in** (Flow)
- **a** (Float)
- **b** (Float)

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Difference

## Properties
None

## Example Usage
a - b
