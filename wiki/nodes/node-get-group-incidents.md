# Get Group Incidents

Gets all incidents in the current case/group.

## Input Ports
- **exec_in** (Flow) - Incoming execution

## Output Ports
- **exec_out** (Flow) - Continues after read
- **incidents** (List) - List of all incident data dictionaries

## Properties
None

## Example Usage
Use in case-triggered automations to process all related incidents.
