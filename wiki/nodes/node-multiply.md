# Multiply Node

Multiplies two numbers.

## Input Ports
- **exec_in** (Flow)
- **a** (Float)
- **b** (Float)

## Output Ports
- **exec_out** (Flow)
- **result** (Float) - Product

## Properties
None

## Example Usage
a * b
